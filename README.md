## Publish
Recommended free option: GitHub Pages.
1. Create a GitHub repository named `rutik1845.github.io`.
2. Upload index.html, css/, and js/.
3. In GitHub: Settings -> Pages -> Deploy from branch -> main -> /(root).
4. Your shareable URL will be `https://rutik1845.github.io/`.

Alternative: Netlify or Vercel can deploy the same static files with a few clicks.
